Нативна програма (PySide6) показує кольорове або монохромне відео з камери з цифровими фільтрами
низьких і високих частот. Розмір вікна фільтра змінюється від 3 до 30 з кроком 1 під час роботи.

### Запуск

```bash
mise trust          # один раз
mise run app        # встановить залежності (uv sync) і запустить програму
```

Інші джерела: `uv run python -m cv.video_filters --source 1` (інша камера),
`--source video.mp4` (файл), `--source synthetic` (тестовий сигнал без камери).
Те саме можна обрати у списку «Джерело».

### Клавіші


| Клавіша | Дія                               |
| ------- | --------------------------------- |
| `8`     | вікно фільтра −1 (мінімум 3)      |
| `9`     | вікно фільтра +1 (максимум 30)    |
| `S`     | знімок результату в PNG           |
| `R`     | початок/кінець запису відео (mp4) |


`8` і `9` працюють і на цифровій клавіатурі, і за утримання (автоповтор). Те саме робить слайдер і
кнопки «−» / «+».
Файли зберігаються в `~/Videos/cv-filters/`.

### Фільтри

Вікно n×n, 3 ≤ n ≤ 30. Кольорове й монохромне відео обробляються однаково (канали незалежно).

- **ФНЧ** — усереднення (ядро з одиниць, CF = n²) або гаусове ядро.
- **ФВЧ** = оригінал − ФНЧ(n): сума коефіцієнтів 0, постійна складова не пропускається. Відображення: *Модуль* (світлі контури на чорному) або *Зсув 128* (сірий рельєф);
підсилення ×1…×10 робить слабкі контури видимими.
- Парні n дозволені; ядро при цьому зсунуте на ½ пікселя.
- «Поруч» показує зліва справжній оригінал (необроблений кадр камери, завжди кольоровий),
справа — результат (монохром і фільтр застосовуються лише до нього).

### Завдання mise


| Команда         | Дія             |
| --------------- | --------------- |
| `mise run sync` | `uv sync`       |
| `mise run app`  | запуск програми |


### Структура

```
src/cv/video_filters/
    filters.py       # ФНЧ/ФВЧ (чиста обробка кадрів, без Qt)
    state.py         # режими та незмінні параметри Params
    sources.py       # камера (V4L2), відеофайл, тестовий сигнал
    capture.py       # потік: захоплення → фільтр → QImage, знімок, запис
    theme.py         # темна тема (токени кольору + QSS)
    widgets.py       # VideoView, Segmented, Card, KeyCap
    main_window.py   # вікно, клавіші, панель керування
tests/               # pytest (+ pytest-qt, offscreen)
```
